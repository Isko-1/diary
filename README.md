# 🎨 Genesis — интерактивный арт-дневник ощущений

> **Проект создан в рамках хакатона.**  
> **Genesis** превращает мимолётные воспоминания дня (текст, живые фотографии, саундтрек, погоду и место) в уникальный эстетичный постер, генеративное полотно и интерактивную виниловую пластинку.

---

## 🌟 Концепция проекта

Обычные дневники хранят сухой текст, а галереи смартфонов — терабайты разрозненных фото.  
**Genesis** объединяет сенсорный опыт прожитого дня в единый мультимодальный артефакт:
1. **Музыка** — воспроизведение трека дня прямо на вращающемся виниле с оригинальной обложкой альбома.
2. **Атмосфера** — генеративное полотно на Canvas, адаптирующее цвета, мазки и текстуру под настроение дня, сезон и реальную погоду.
3. **Кастомизация** — полная свобода компоновки элементов, стикеров, плейлиста, заметок и ретро-кассеты.
4. **Хроника** — горизонтальный таймлайн-календарь с цветовой подсветкой собранных дней по шкале эмоционального тона.

## 🤖 Искусственный интеллект и технологии разработки

В создании и работе проекта ключевую роль сыграли передовые технологии искусственного интеллекта:

### 1. Агентная разработка: Google Antigravity & Claude 3.7 Sonnet
- Проект спроектирован, структурирован и разработан в автономной среде **Google Antigravity**.
- Архитектура приложения, решение комплексных фронтенд-задач (CORS Canvas в мобильном Safari, математические трансформации матриц перетаскивания и вращения элементов, интеграция внешних API) реализованы при помощи модели **Claude 3.7 Sonnet**.

### 2. Мультимодальный анализ данных (AI Pipeline)
- **Анализ текста дня (Claude API / Anthropic):**
  - Определение эмоционального профиля текста: **Valence** (приятность/позитив), **Arousal** (энергия/напряжённость) и **Warmth** (душевное тепло).
  - Автоматическая формулировка ёмкого названия дня (3–7 слов) и выделение ключевых контекстных маркеров.
- **Оценка аудио-признаков (ReccoBeats & LLM):**
  - Анализ темпа (BPM), тональности (мажор/минор) и динамической энергии трека. Если прямой анализ стриминга недоступен, модель вычисляет вероятностный профиль композиции по названию и артисту.
- **Сенсорное слияние (Sensor Fusion Algorithm):**
  - Модуль `lib/fuse.ts` математически объединяет визуальные данные палитры фото, эмоциональный вектор текста и ритм музыки в единую гармоничную точку пространства настроения.

## 🚀 Ключевой функционал

### 🖼️ Генеративный холст (HTML5 Canvas 1080×1350)
- **Живописные стили:** генерация уникальных слоёв мазков и геометрических паттернов в стилях **Клода Моне** (импрессионизм), **Анри Матисса** (декоративные аппликации), **Василия Кандинского** (абстрактная геометрия) и **Минимализма**.
- **Художественные фотофильтры:** пользователь может переключать стили на свой вкус:
  - ✨ *Настроение дня* (автоматический адаптивный выбор)
  - 📷 *Оригинал* (чистая фотография без фильтрации)
  - 🎞️ *Плёнка* (тёплый аналоговый контраст с лёгкой сепией)
  - ⬛ *Ч/Б*, 🌅 *Тёплый*, 🌊 *Прохладный*
- **Управление текстовыми метками:** возможность в один клик отключать/включать заголовок стиля, дату или подпись трека для достижения идеального минимализма.

### 💿 Интерактивный винил и саундтрек
- **Настоящий плеер с превью Deezer API:** воспроизведение музыки при клике на винил или по кнопке в плеере.
- **Обложка альбома на яблоке пластинки:** автоматическая подгрузка обложки трека в центр винила. Доступны альтернативные стили лейбла (фото дня, ретро-лейбл, палитра дня, минимал).
- **Выбор фрагмента песни (таймлайн):** настройка момента старта воспроизведения 30-секундного отрывка (0с, 5с, 10с, 15с, 20с).
- **Синхронизация скорости вращения:** темп пластинки плавно адаптируется под реальный BPM звучащего трека.

### ✂️ Свободная кастомизация сцены (Free Canvas Drag & Drop)
- Прямое манипулирование объектами: **перетаскивание, масштабирование (zoom/колёсико/маркеры) и вращение за крутилку на 360°**.
- Элементы можно размещать **абсолютно везде** (выносить за пределы постера, формируя журнал-коллаж).
- Набор наклеек и виджетов:
  - 🌦️ *Погода* (интерактивный виджет с температурой, осадками и ветром)
  - 🗺️ *Карта местности* (мини-карта OpenStreetMap по геопозиции)
  - 🏷️ *Бейдж локации* и 📝 *Текстовые заметки-стикеры*
  - ✨ *Эмодзи и стикеры*, 🎗️ *Декоративный скотч*
  - 📼 *Ретро-кассета* и 📋 *Интерактивный треклист*

### 📅 Горизонтальный календарь-таймлайн месяца
- Линейка всех дней месяца в длину.
- Дни с воспоминаниями подсвечиваются высокими цветными столбиками настроения:
  - 🟠 *Энергично* (`#ff7a59`)
  - 🟡 *Светло* (`#f5d86b`)
  - 🟣 *Мечтательно* (`#b7a6f2`)
  - 🟢 *Спокойно* (`#8cc9b4`)
  - ⚪ *Нейтрально* (`#c9d0e3`)
- **Быстрый переход:** клик по пустому дню открывает создание воспоминания **сразу с предзаполненной выбранной датой**.

### 🌦️ Интеллектуальная геолокация и погода
- Точный геокодинг Nominatim с поддержкой уточнения страны (например, «Уральск, Казахстан»).
- Автоматический запрос исторической погоды Open-Meteo строго за выбранную дату воспоминания.

## 🛠️ Стек технологий

- **Фреймворк:** [Next.js 15 (App Router)](https://nextjs.org/) + TypeScript + React 19
- **Стилизация:** Tailwind CSS + CSS Container Queries (`cqw` / `cqh`)
- **UI-компоненты:** Magic UI (`MagicCard`, `BlurFade`, `GridPattern`)
- **Цветовое пространство:** [Culori](https://culorijs.org/) (пространство OKLCH для гармоничного сдвига палитр)
- **Хранилище:** IndexedDB (`idb-keyval`) — все личные данные и фотографии остаются локально в браузере пользователя
- **Музыкальные сервисы:** Deezer API (поиск метаданных, обложек и 30-секундных аудио-превью), YouTube & Spotify oEmbed
- **Картография и погода:** OpenStreetMap Tiles, Nominatim Geocoding, Open-Meteo Historical Weather API
- **Типографика:** Google Fonts (`Unbounded`, `Fraunces`, `Caveat`, `JetBrains Mono`)

## ⚡ Быстрый старт

### 1. Клонирование и установка зависимостей
```bash
git clone https://github.com/Isko-1/diary.git
cd diary
npm install
```

### 2. Настройка переменных окружения
Создайте файл `.env.local` в корне проекта:
```bash
cp .env.example .env.local
```
Добавьте ваш ключ API (при отсутствии ключа автоматически задействуется качественная эвристика анализа):
```env
ANTHROPIC_API_KEY=your_claude_api_key_here
```

### 3. Запуск сервера разработки
```bash
npm run dev
```
Откройте [http://localhost:3000](http://localhost:3000) в браузере.

### 4. Продакшн-сборка
```bash
npm run build
npm run start
```
